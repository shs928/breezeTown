# UI-01 美术方向稿：像素风

状态：**方向稿**，不是最终资产。最终素材由 ART-01 在 SEC-01 后入包，必须登记许可证；本稿只确定风格约束与色板，供 UI-02 用占位素材实现。

## 1. 风格定位

原创 2D 俯视角统一像素风。基础格 32×32 px；角色 32×32；一屏 1280×720 显示 40×22.5 格。目标观感：明亮、柔和、低饱和度的田园色调，不做暗黑/写实；所有资产原创或使用许可清楚的免费素材，禁止复制既有作品素材。

## 4. 农场与公共区布局（方向）

- 中央 12×12 耕地区（扩展后 16×16），四周开阔草地；边界装饰树/篱笆不可破坏。
- 公共区集中在步行可达范围：种子商店、出售点、共享仓库、建设板、榜单入口。
- 四角出生点；玩家之间不实体阻挡，静态碰撞只作用于地图。
- 设施用招牌图标 + 文字标签标识，不依赖颜色。

## 5. UI 视觉

- 面板：浅色底 `#F5EFE3` + 深色描边，圆角小；按钮 hover 高亮 `#F2D06B`。
- 字体：简体中文可用点阵/像素字体（许可证必须登记）；正文最小 16px 等效，标题 24px 等效。
- 数字（资金/数量/榜单）用等宽数字，右对齐。
- 图标风格统一 32×32 像素网格。

## 6. 音效方向（ART-01 落地）

- 轻量环境音 + 操作反馈音（播种、浇水、收获、出售、建设完成）。
- 音效素材必须原创或 CC0/许可清楚；不做语音。
- 提供主音量/音效音量设置；无音频设备时不崩溃（dedicated 不加载音频）。

## 7. 与验收的关系

- 本稿支撑 CASE-42/44 的视觉与素材许可要求，但**不构成视觉验收通过**；占位方块截图不得当最终视觉（PRD 第 14 章红线）。
- UI-02 用占位素材实现流程；ART-01 替换为最终统一素材并登记许可。
