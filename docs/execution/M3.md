## 2. 本轮修复的真实缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| 远端只能执行管理命令 | 客户端无法种地/买卖/建设 | `LocalSession._install_handlers()` 统一装配全部处理器 |
| 房主本地操作不广播差量 | 客户端 revision 永久落后 | `_submit` 后调用 `broadcast_delta()` |
| 日切不推进 `business_revision` | 客户端看不到新的一天 | 日切作为业务提交递增 revision |
| `SyncBuffer.push` 假设每次提交只 +1 | 跳号时误跳过差量 | 改为与已推送最高 revision 比较 |
| 救济检查顺序 | 当日重复领取误报“资金不足” | 当日已领优先判定 |
| 空载荷命令被误判无 spec | `claim_relief` 被拒 | `_payload_specs` 用 null 表示未定义、{} 表示合法空载荷 |
| Callable 持有局部 RefCounted 被回收 | 生长结算静默失效 | 调用方保持处理器引用 |
