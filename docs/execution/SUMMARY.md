## 6. 过程中发现并修复的真实缺陷（部分）

1. **Godot 4.7 高层 API 无 DTLS** → 生产改用低层 `ENetConnection` + `TLSOptions`。
2. **JSON 数字解析为 float** → 网络/存档/连接卡三处按契约归一化，否则 `protocol_version: 1` 被判为 `1.0`。
3. **房主本地操作不广播差量** → 客户端 revision 永久落后。
4. **日切不推进 revision** → 客户端看不到新的一天。
5. **远端只能执行管理命令** → 统一装配全部处理器。
6. **`grep -q` + `pipefail` 误杀 Godot** → 检查脚本改为先捕获输出。
7. **同一秒连续导出互相覆盖** → 导出目录名加毫秒与序号。
8. **Callable 持有局部对象被回收** → 生长结算静默失效。

## 8. 结论与下一步

**M0–M5 的技术目标已达成**：核心玩法闭环、多人联机、数据可靠性、公开导出与迁移均有可复现证据。**0.1.0 候选包已构建，但不具备发布条件**——M6 的真人验收、双平台实机与真实网络证据缺失。

建议的下一步（按优先级）：
1. 提供 Windows 实机与两套真实家庭网络 → 解锁 QA-02、INT-02。
2. 提供 5 名未参与开发的新手 → 解锁 QA-03 与 CASE-37/42 真人验收。
3. 决定音效预算 → 补齐 ART-01 的音频部分。
4. 上述资源到位前，可继续打磨玩法与修复已发现的 Major 缺陷，但不得标记 0.1.0 为已发布。
