# 微风小镇 0.1.0 用户手册

适用版本：0.1.0（封闭测试包）｜更新日期：2026-09-09

## 1. 这是什么

一款 2D 俯视角合作农场小游戏。1 人可玩，2–4 人联机；由房主保存世界，大家种植、浇水、收获、出售、完成公共建设；游戏内显示累计收益、当日收益和贡献榜，可经授权导出公开榜单。

## 2. 安装与启动

**macOS**：解压 `BreezeTown.zip`，双击 `微风小镇.app`。首次打开若被系统拦截，右键选择“打开”。

**Windows**：解压后运行 `微风小镇.exe`（**Windows 实机尚未验证**，见第 8 节）。

启动参数（命令行，供专用服使用）：
```sh
./微风小镇 --headless -- --mode=dedicated --world-dir=<世界目录绝对路径> --port=24642
```

## 3. 基本操作

| 操作 | 默认键位 |
|---|---|
| 移动 | W / A / S / D |
| 指向与操作 | 鼠标左键 |
| 交互设施 | E |
| 快捷栏 | 数字 1–6 |
| 背包 | Tab |
| 榜单 | L |
| 菜单 | Esc |

工具栏提供锄头、水壶、空手三个选项。选中种子后进入播种状态。水壶水量无限，无需装水。

**重要**：打开菜单不会暂停世界（单人也一样），页面顶部会提示“世界仍在运行”。

## 4. 怎么玩

1. **创建世界**：主菜单填写昵称和世界名，选择“单人”或“允许联机”。
2. **获得种子**：走到种子商店按 E 购买。
3. **整地种植**：选锄头点击空地整地，再选种子点击耕地播种。
4. **浇水**：选水壶点击作物。**当天浇过水的作物，日切后才会生长**；没浇水不会死亡，只是停长。
5. **收获**：作物成熟后空手点击收获，产物进入背包。
6. **出售**：走到出售点按 E，把产物卖出换取共享农场资金。
7. **看榜单**：按 L 查看累计收益、当日收益、累计贡献三张榜。
8. **公共建设**：在建设板捐赠指定产物，按顺序解锁三项建设，完成后仍可继续经营。

一个游戏日约 10 分钟现实时间（06:00 起算）。

## 5. 联机

**房主**：
1. 主菜单创建世界时选“允许联机”（或继续世界时开启）。
2. 开服后把**连接卡**发给朋友（含地址、端口和服务器证书）。

**加入者**：
1. 主菜单粘贴连接卡，点击“加入世界”。
2. 确认服务器身份（核对世界名），等待房主批准。
3. 批准后即可进入同一个世界。

**网络要求**：需要房主的地址可达、目标端口（默认 24642）已放通。V1 **不提供官方中继**，也无法自动配置路由器。

- 同一局域网通常可直接连。
- 跨家庭网络需要公网可达地址 + 端口转发。
- 处于运营商 CGNAT 之后可能无法直连，这属于网络环境限制，**重试不会解决**。

## 6. 存档与备份

- 世界由房主保存，自动保存间隔约 30 秒；日切、成员变化和正常退出也会保存。
- 界面区分“操作已生效”和“最近成功保存”。
- **保存失败时世界会立即暂停**并提示，可重试保存或另存恢复包；退出时不会假装保存成功。
- 保留最近 5 份自动快照；手动备份不会被自动清理。

## 7. 公开榜单

公开**默认关闭**，需要两道授权：房主开启世界公开开关 + 每名成员自己同意。只有同意的成员会出现在导出的榜单里，且会按公开成员重新排名。导出为 HTML + JSON 两个文件，可离线打开，不含脚本或网络请求。

**注意**：别人已经下载的静态文件无法由游戏自动收回。

## 8. 已知限制（务必阅读）

1. **房主是世界权威**：房主退出或崩溃时其他玩家不能继续推进，可能回退到最近一次有效保存。
2. **不做房主防作弊**：房主控制存档，V1 不承诺官方公平或不可篡改。
3. **网络边界**：不提供中继和一键 NAT 配置；CGNAT、IPv6-only 等场景不保证直连。
4. **平台验证状态**：macOS Apple Silicon 已实测；**Windows x64 尚未在实机验证**；Linux 完整发行包不在本版范围。
5. **尚无音效**：当前版本无背景音乐和音效。
6. **未验证项**：真实异地联机、四人真实网络回归、五名新手体验测试仍在进行中。

## 9. 迁移到自建服务器

1. 房主关闭世界并确认保存成功。
2. 导出私有迁移包（含世界快照与必要私有配置）。
3. 在目标机器用 `--mode=dedicated` 导入并启动。
4. 原成员用原身份加入。世界、成员、库存、资金、榜单、游戏日和建设都会保留。

**注意**：同一世界不能双开；如服务器证书改变，必须重新分发连接卡。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 加入失败，提示证书错误 | 确认连接卡来源可信；证书更换后需用新卡 |
| 提示“等待房主批准”后超时 | 请房主在批准列表确认；申请 60 秒过期 |
| 提示“服务器已满” | 在线上限 4 人（含房主） |
| 提示“版本不一致” | 双方使用同一版本客户端 |
| 提示“保存失败，世界已暂停” | 点击重试，或另存恢复包后检查磁盘空间/权限 |
| 无法直连 | 检查地址与端口转发；CGNAT 环境 V1 不保证可连 |
