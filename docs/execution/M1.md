## 2. 关键实现要点

- **UI 不碰权威状态**：ClientRoot 所有动作方法（`action_*`）都经 `WorldRuntime.submit` → 契约校验 → 处理器 → 原子提交；集成测试驱动的是这些真实方法，不是 mock。
- **提交计划模式**：处理器只返回 `{ops, events, stat_ops}`，由 TransactionCoordinator 整体校验后一次性应用，直接满足 NFR-01。
- **原子性跨日**：日切时 FARM 的生长结算与日切在同一批次内完成（`set_day_settle_hook`），不存在半日状态。
- **身份与存档分离**：凭据明文只存 `user_data/identity/<world_id>.json.cred`，世界快照只含 SHA-256 摘要（测试含泄漏断言）。
- **JSON 数字归一化**：Godot 的 `JSON.parse_string` 把数字读为 float，仓库加载时按契约 4.2 归一化整值 float 再校验。
