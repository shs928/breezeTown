## 2. 关键实现要点

- **高层 API 不可用**：Godot 4.7 的 `ENetMultiplayerPeer` 无 DTLS 选项（NET-01 证实），正式传输基于低层 `ENetConnection` + `TLSOptions`，与实验一致。
- **认证前不下发私有数据**：`welcome` 只在批准后发送，且快照经 `WorldView` 按成员过滤（复用 `ContractView`，不另写一套）。
- **身份连续性**：历史成员凭摘要直接恢复；重复身份拒绝新连接而不踢掉在线者；撤销记录摘要阻止重入；重绑保留 `player_id`/背包/统计。
- **席位含房主**：`local_host_online` 控制，4 人上限含房主（CASE-47）。
- **差量推送覆盖本地操作**：房主本地操作与远端命令都调用 `broadcast_delta()`——这是本轮修复的真实缺陷（原先只有远端命令推送，导致客户端 revision 落后）。
- **JSON 数字归一化**：网络解码、连接卡解析、存档加载三处都按契约 4.2 归一化整值 float，否则 `protocol_version: 1` 会被判为 `1.0` 而拒绝。
- **脱敏日志**：键名或值命中敏感词即替换；64 位 hex 只保留前缀。
