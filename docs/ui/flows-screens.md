# UI-01 页面与状态表

所有页面标注：入口、可见反馈、下一步、失败态。文案用本地化键（`ui.*`），本文中文仅为当前语言值。

## 1. 主菜单

| 项 | 内容 |
|---|---|
| 入口 | 启动游戏（solo / listen_host / client 都先进主菜单） |
| 按钮 | 继续世界、创建世界、加入世界、设置、退出 |
| 世界列表行 | 世界名、游戏日、最后成功保存时间、最后运行版本、可加载状态 |
| 不可加载行 | 显示原因（损坏/版本不兼容）+ “恢复上一版本”入口；**不自动新建同名空世界** |
| 锁冲突 | 启动即弹提示“该世界已被另一个实例打开”，提供“只读查看/退出”，不覆盖 |
| 下一步 | 进入对应流程 |

## 2. 创建世界

| 项 | 内容 |
|---|---|
| 字段 | 世界名（≤32 字符，空白拒绝）、昵称（同上） |
| 模式 | “单人” / “允许联机”（二选一，显示本世界规则摘要） |
| 反馈 | 名称为空/超长即时红字；创建中显示进度；完成首次保存后提示“已创建并保存” |
| 下一步 | 进农场；世界列表出现该世界 |

## 3. 加入世界（客户端）

| 状态 | 界面 | 失败态与下一步 |
|---|---|---|
| 输入地址 | 地址/端口输入 + “粘贴连接卡” | 格式错误即时提示 |
| 确认服务器身份 | 显示连接卡中的世界名 + 证书指纹（可复制核对） | 指纹不符 → “取消” |
| TRUST_CHECK/AUTHENTICATING | 进度：建立加密连接…（≤15s） | 超时/证书错误 → 明确失败 + 重试 |
| WAIT_APPROVAL（新成员） | “等待房主批准…”（≤60s） | 拒绝/超时 → 返回可重试页 |
| SYNCING | “正在同步世界…”（≤10s） | 失败 → 重试 |
| ACTIVE | 进入农场 | — |

## 4. 农场 HUD

| 元素 | 位置 | 内容 |
|---|---|---|
| 工具栏 | 左下 | 锄头 / 水壶 / 空手 三个可点击项，当前项高亮 + 文字标签 |
| 快捷栏 | 底部中央 | 6 格，显示物品图标 + 数量；数字 1–6 选择 |
| 资金 | 右上 | 共享农场资金（金币图标 + 数值） |
| 游戏时间 | 右上 | “第 N 日 08:30” |
| 保存状态 | 右上角 | “已保存 12 秒前” 或 “⚠ 保存故障：已暂停（原因）” |
| 在线成员 | 左上 | 头像/配色 + 昵称 + 在线点 |
| 状态提示 | 屏幕下方居中 | 一次性提示（如“浇水成功，今日已计分”） |

关键规则：**背包满/距离过远/数量不足/资金不足/正在同步/断线**都有对应错误条，文案来自错误码映射，不含堆栈。

## 5. 背包与快捷栏整理

| 操作 | 反馈 |
|---|---|
| Tab 打开 | 24 格网格；6 个快捷栏格有角标 |
| 拖拽/整组移动 | 目标格高亮；非法目标（他人容器/越界）置灰 |
| 拆分数量 | 弹出数量选择（1..99）；超出可用数量拒绝并提示 |
| 整理到快捷栏 | 立即生效；失败整笔回滚，提示原因 |
| 中文输入 | 输入框获得焦点时**不触发移动/地面动作**（见 input-contract） |

## 6. 种子商店

| 项 | 内容 |
|---|---|
| 入口 | 走到商店按 E |
| 列表 | 5 种种子：名称、单价、当前资金 |
| 操作 | 买 1 / 买 10 / 数量输入；确认前显示总价 |
| 反馈 | 资金不足 → 红字“资金不足（需 X，现有 Y）”；成功 → 资金扣减 + 种子入包提示 |
| 限制 | 只卖种子；价格由服务器定义，界面不可编辑金额 |

## 7. 出售点

| 项 | 内容 |
|---|---|
| 列表 | 背包中的作物产物 + 数量 |
| 预览 | “出售 10 个萝卜 = 240 金币” |
| 反馈 | 成功后资金增加、收益榜更新；旁边固定说明“出售收入，非净利润” |
| 拒绝 | 种子/工具不可售（不出现或置灰） |

## 8. 共享仓库

| 项 | 内容 |
|---|---|
| 两栏 | 我的背包 | 共享仓库（格数与容量显示） |
| 操作 | 指定格与数量转移；版本冲突 → “物品已被他人取走” |
| 满仓 | 放入失败提示容量不足，整笔不部分成功 |

## 9. 公共建设板

| 项 | 内容 |
|---|---|
| 列表 | 3 个项目，按顺序解锁；未解锁显示前置条件 |
| 单项 | 需求清单（已交/还需）、进度条、“捐赠”按钮 |
| 超额 | 输入超过缺口 → 整笔拒绝并提示“当前还需 X” |
| 完成 | 播放完成反馈 + 效果生效提示；已完成项不可再捐 |
| 救济 | 条件满足时出现“领取救济种子”按钮；不满足时说明“仍有可用资金/作物/物品” |

## 10. 榜单（L）

| 项 | 内容 |
|---|---|
| 三张榜 | 累计收益 / 当日收益 / 累计贡献，可切换 |
| 行 | 名次（并列同号）、昵称、数值、在线状态；本人行高亮 |
| 说明 | 固定显示“出售收入，非净利润”“游戏第 N 日”“按有效操作计分，不代表劳动价值” |
| 明细 | 点击本人 → 贡献分类（种植/浇水/收获/捐赠）+ 规则版本 |
| 离线/撤销 | 历史行保留，撤销标“已停用” |

## 11. 公开选择与导出

| 项 | 内容 |
|---|---|
| 双重授权 | 世界开关（仅所有者可见）+ 每名成员自己的“同意公开”开关 |
| 别名 | 可选“使用昵称”或“公开别名”；撤回后影响后续导出 |
| 预览 | 显示即将公开的三榜和世界展示名，**不含**连接卡/私有 ID/IP |
| 导出 | 生成 HTML + JSON（无脚本/无网络请求）；失败不覆盖上一有效文件 |
| 提示 | “他人已下载的文件无法自动收回”；房主离线后网页为最后快照 |

## 12. 保存故障与恢复

| 状态 | 界面 |
|---|---|
| 保存故障 | 全屏横幅“保存失败，世界已暂停”；显示最近成功保存时间与原因 |
| 可选操作 | 重试保存 / 另存恢复包到其他目录 / 放弃未保存进展并退出 |
| 恢复旧备份 | 列出可恢复代（时间/游戏日），确认后提示“成员需重新绑定与重新授权” |

## 13. 设置

| 项 | 内容 |
|---|---|
| 音量 | 主音量 / 音效音量 |
| 显示 | 窗口 / 全屏、UI 缩放 |
| 键位 | 完整重绑定 + 恢复默认 + 冲突检测提示 |
| 提示 | 菜单不暂停世界（单人也一样），页面顶部固定提示“世界仍在运行” |

## 14. 错误文案映射（抽样）

| 错误码 | 玩家可见文案 | 下一步 |
|---|---|---|
| INVENTORY_FULL | 背包已满 | 整理背包或存入仓库 |
| INSUFFICIENT_FUNDS | 资金不足 | 出售作物或调整数量 |
| INSUFFICIENT_ITEMS | 物品不足 | 检查数量 |
| TARGET_CHANGED | 目标已变化 | 重新选择 |
| STALE_STATE | 状态已更新 | 界面自动刷新后重试 |
| RATE_LIMITED | 操作太快 | 稍后重试 |
| SAVE_FAILED / SAVE_UNAVAILABLE | 保存失败，世界已暂停 | 重试保存或另存 |
| SYNC_REQUIRED | 需要重新同步 | 自动重同步 |
| VERSION_MISMATCH | 版本不一致，无法加入 | 使用同版本客户端 |
| SERVER_CLOSING | 房主已关闭世界 | 返回主菜单 |
