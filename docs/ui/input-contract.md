# UI-01 输入与焦点契约

对应 PRD 4.4、CASE-07/08/38；M0 为设计契约，UI-02 实现、UI-06 完整重绑定。

## 1. 默认键位

| 操作 | 键 | 备注 |
|---|---|---|
| 移动 | WASD | 方向归一化；速度 96 px/s |
| 指向/操作 | 鼠标左键 | 对一格执行当前动作，每次点击只提交一次 |
| 交互 | E | 打开最近且处于有效交互区的设施；同距按设施 ID 固定排序 |
| 快捷栏 | 数字 1–6 | 选择背包快捷栏物品 |
| 背包 | Tab | 打开/关闭 |
| 榜单 | L | 打开/关闭 |
| 菜单 | Esc | 打开/关闭；**不暂停世界** |

工具栏（锄头/水壶/空手）为可点击项；选中种子后进入播种状态，点击工具切回工具状态。水壶水量无限，无装水步骤。

## 2. 输入焦点规则（硬约束）

1. **UI 获得焦点时不得触发地面动作**：任一 `LineEdit`/`TextEdit`/模态弹层处于焦点时，移动键与鼠标地面点击全部屏蔽（事件在 UI 层消费）。
2. **中文输入不移动角色**：输入法组合期间（IME composing）同样不产生移动/地面动作；仅确认后的文本进入输入框。
3. **模态弹层**：确认框、数量输入、保存故障横幅为模态时，只响应弹层内控件；Esc 关闭非破坏性弹层（破坏性确认需显式点击）。
4. **菜单不暂停多人世界**：菜单打开时世界照常推进；菜单顶部固定提示“世界仍在运行”。V1 单人也同规则。
5. **焦点丢失**（切到其他窗口）：世界继续推进，不主动暂停（PRD 5.2）；系统休眠不补跑。

## 3. 键位重绑定与冲突（CASE-38 设计准备）

- 每个动作可绑定一个主键 + 一个备用键；重绑定流程：点击动作 → 按新键 → 若与既有绑定冲突，提示“该键已用于 X”并要求换键或清除。
- 必须保留“恢复默认”入口；重绑定写入设置并在重启后保持。
- 鼠标左键/右键不允许被重绑定到地面动作以外的用途（避免与 UI 冲突）。
- 窗口/全屏/UI 缩放/音量设置即时生效并可保存。

## 4. 可辨识性（不只依赖颜色）

- 三种工具：形状 + 文字标签 + 选中态边框三重区分。
- 五作物阶段：形态差异 + 阶段名提示；成熟作物有明显视觉标记。
- 浇水状态、可耕地、阻挡格：纹理/图案差异，不仅颜色。
- 错误提示：图标 + 文案，颜色只作辅助。

## 5. 键盘导航与可达性（设计目标，M6 复核）

- 主菜单/设置/榜单可用 Tab 键在控件间移动，Enter 激活。
- 关键状态（保存故障、断线、同步中）有文字说明，不只用动画。
- UI 缩放在 100%–150% 区间保持布局不重叠。

## 6. 与实现的边界

- UI 只调用 `CommandGateway`（本地或网络入口），**不直接写权威状态**（NFR-06）。
- 输入层负责把键鼠事件转成有界命令（含 `input_sequence`），由应用层校验距离/频率/权限。
- 具体控件节点与场景由 UI-02 落地；本契约是验收依据，不是节点清单。
