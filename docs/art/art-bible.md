## 一、整体风格

**等距手绘卡通乡村（Isometric / Stylized 3D / Hand-painted / Cozy / Rural Fantasy / Soft Lighting）。**

- 视角：等距/近等距，斜上方观察；Orthographic 优先，跟随相机允许弱透视。
- 建模：中低面数、大轮廓、圆润倒角；禁止尖锐写实细节。
- 材质：手绘感、弱 PBR；哑光为主，仅成熟提示、灯窗、水面使用自发光。
- 光照：柔和环境光 + 单一日光方向；阴影柔和但轮廓清晰；夜间以暖色点光（灯柱、窗光）点缀。
- 色彩：暖色乡村（原木棕、稻草黄）+ 清新自然色（嫩绿、天蓝）；整体明快、低饱和对比、无纯黑。

## 三、各资产类别规则

- **建筑**：童话式乡村小屋，圆润体积，木构架 + 抹灰墙，坡屋顶（蓝瓦/红瓦/茅草三系），门牌可读；禁止对称呆板的方盒。地图图标只提供位置，屋檐、层高、门宽、台阶和碰撞均需按米制空间检查，不能按图标像素宽度直接放大。
- **地形**：草地、泥土、石块、花草形成手绘层次；山体以草坡 + 岩壁收边；水体明亮蓝绿带波纹与浅滩。
- **植物**：大轮廓、蓬松、夸张；松树锥形层叠，阔叶树团状，花丛点缀色块。
- **角色**：卡通比例（约 3 头身），轮廓清晰；农夫＝草帽 + 背带裤 + 靴子；装备必须挂在手部插槽并跟随动画。
- **动物**：圆润蓬松，体型略夸张（大头短腿），牛/羊/鸡轮廓一眼可辨。
- **道具**：轻微夸张比例突出可读性（宝箱、木桶、灯柱、邮筒、水井）。
- **VFX**：柔和粒子（浇水水花、收获星光、受击飘字），禁止硬边光效。

## 四、UI 规范（依据 ui-hud.png）

**材质语言：木质面板 + 羊皮纸内衬 + 叶片装饰，手工感；圆角、厚描边、暖色投影。**

### 版式（HUD）

```text
┌─────────────┐                                      ┌──────────────────────────────┐
│ 头像 / 农场名│                                      │ 季节│日期│天气│ 时钟 │
│ ♥ 生命条     │                                      └──────────────────────────────┘
│ 口粮 ×N · Q  │                                        ┌──────────────┐
└─────────────┘                                        │ ◉ 金币数     │
                                                       └──────────────┘

                    ┌──────────────────────────────────┐
                    │ 快捷栏：图标槽 ×9 + 数量角标       │
                    └──────────────────────────────────┘
                                        ┌────────────────────────┐
                                        │ 🔔 任务/提示通知（右下） │
                                        └────────────────────────┘
```

- **左上状态板**：当前显示圆形头像、农场名、心形生命条和口粮库存。生命为 `当前 / 上限`；口粮为真实 `口粮 ×N` 与 `Q 食用`，为零显示已用完，不用生命上限 100 表达库存。参考图中的等级、经验与体力在对应玩法实现后再接入，不显示虚构数值。
- **右上信息排**：季节、日期、天气、时钟与下一行金币木牌，使用真实时钟和经济状态。当前为统一纸面信息排；参考图里的分段图标胶囊仍是后续目标。金币使用千分位，不提供没有对应功能的加号按钮。
- **底部快捷栏**：木质横条、无字羊皮纸底格、透明工具图标；选中槽金色描边、微光与底部标记。快捷键和库存数量分开绘制，不能残留参考图的示例数字。
- **提示/通知**：当前有底部情境提示与临时消息；右下角完整任务通知板仍待任务系统接入。不要用示例任务文字冒充已实现功能。
- **面板（背包/商店/地图/升降机）**：木质外框 + 羊皮纸内衬 + 布纳罗纹样边饰（暂以深棕描边代替）；标题左对齐，副标题小字灰棕。
- **字体**：项目内置 OFL 中文字体；正文墨棕 `#5a4632`，辅助 `#8a7358`，高亮 `#e8bf62`。

### 交互反馈

- 选中目标为金色描边与明确高亮；当前使用描边、光晕和底部标记，不因边框宽度变化挤动格子。不可用状态应有颜色与文字提示。
- 变化动效目标：金币/资源数字滚动或弹跳一次、通知滑入滑出；当前未完成统一动效，不作为既有能力登记。
- 禁止：系统原生灰按钮直接暴露给玩家，一律套用木框样式。

## 五、离线资产与可复现流程

当前采用混合资产流程，不再把“全部模型在运行时由代码生成”作为现状：

| 类别 | 当前生成 / 编辑来源 | 游戏实际使用 |
|---|---|---|
| 农舍、商店、谷仓、鸡舍 | 建筑 GDScript → `export_architecture.gd` 导出 GLB → `prepare_architecture.py` 转存可编辑 `.blend` | `game/resources/models/` 中对应 GLB |
| 成年松树、橡树、苹果树 | `tools/art/blender/build_foliage.py` 在 Blender 生成，保存 `.blend` 与 GLB | 成年树优先加载 GLB；幼苗仍有程序网格 |
| 其他乡镇建筑、地形、道路、部分道具与角色 | `game/scripts/art/` 中的生成代码 | 程序几何与共享材质 |
| 建筑 / 地表纹理 | `build_architecture_materials.py`、`build_surface_textures.py`，固定随机种子 | 原创程序颜色贴图、浅法线和地表纹理 |
| HUD | `build_reference_ui.py` 清理参考图样例文字、抠出图标，并补绘缺失工具 | 木框、纸面与图标 PNG，数值由 HUD 绘制 |
| 地图数据与植被掩码 | 蓝图 JSON 人工描图；`build_map_trace.py` 生成检查图与颜色掩码 | 第一张地图的米制定义与近处森林分布 |

完整命令、依赖、输出路径及覆盖规则见 [地图资产重建流程](../maps/first-map.md#可复现资产流程)。建筑 `.blend` 当前是 GLB 的可编辑副本，尚无与 GDScript 的双向同步。更改任一来源后必须检查游戏实际加载的 GLB / 贴图，不能只更新源文件或编辑器截图。

现有资产是向目标画风迭代的实现，不因原创或程序生成自动通过风格审查。逻辑仍应通过 ID、数据和服务调用表现层；区域比例、碰撞规则、资源数量不能藏进纯表现脚本。

| 玩法内容表现 | 有种植、养殖、资源与矿场基础表现 | NPC 服务、任务、完整季节天气、音效等仍未完成 |
